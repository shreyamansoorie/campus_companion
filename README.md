# campus-companion

**Your campus life, organized in one place!**

Campus Companion is a student-focused mobile application designed to make everyday academic life easier and more organized.
The app brings essential academic tools together in one place, helping students manage their schedules, track attendance, calculate attendance requirements, and share notes with classmates.

##  Features

### 📅 Timetable Management
- View and manage daily class schedules.
- Keep track of upcoming lectures.
- Stay organized throughout the semester.

### 📊 Attendance Tracker
- Track attendance for individual subjects.
- Monitor attendance percentages.
- Get a clear overview of your attendance status.

### 🧮 Attendance Calculator
- Calculate how many classes you can skip while maintaining the minimum 75% attendance requirement.
- Find out how many additional classes you need to attend to reach 75%.
- Make smarter decisions about attendance.

### 📚 Shared Notes
- Share notes and study materials with classmates.
- Access resources shared by other students.
- Build a collaborative learning environment.

## 🛠️ Tech Stack
- Flutter: Cross-platform mobile app development 
- Dart: Application programming language 
- Firebase: Backend and cloud services 
- Cloud Firestore: Database management 
- Firebase Authentication: User authentication
